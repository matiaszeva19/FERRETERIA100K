# Inputs — Material Crudo para el Equipo de Agentes

Tirá acá todo el material en bruto para que el Agente Maestro y los subagentes lo procesen sin ensuciar el `cerebro/`:

- `referentes/`: Links, notas o transcripciones de videos/cuentas que te gusten para copiar estructura (no contenido).
- `metricas/`: Capturas de estadísticas, listas de vistas/guardados/consultas o CSVs de IG/TikTok/Facebook.
- `productos_crudos/`: Listas de precios, fotos, catálogos de proveedores o notas rápidas que pase la dueña sobre la nueva línea minorista.
