# Bajada a Web y Mercado Libre (Línea Minorista)

## Objetivo
Transformar productos de la ferretería en ofertas claras, rentables y listas para vender por internet sin generar cuellos de botella en mostrador o logística.

## Pasos

1. **Consultar estado actual**:
   - Lee `cerebro/02_linea_minorista_y_catalogo.md` y `cerebro/04_canales_web_y_meli.md`.
2. **Filtrar viabilidad del producto (Check de Realidad)**:
   - ¿Ticket unitario muy bajo? -> Proponer **combo o pack** (ej. pack x3, kit de instalación) para que comisiones y envío no destruyan el margen.
   - ¿Muy pesado o frágil para correo? -> Marcar como **Solo Retiro en Campana / Envío local**.
3. **Construir la Ficha de Producto**:
   - **Título SEO Mercado Libre (máx. 60 caracteres):** `[Producto] + [Marca/Material] + [Medida/Uso clave] + [Cantidad]`. Sin relleno ("imperdible", "oferta").
   - **Bullets clave para Web / Descripción:** Qué resuelve, medidas exactas, qué incluye y qué NO incluye (para evitar reclamos/devoluciones).
   - **Fotos/Clips necesarios:** Foto limpia principal + foto en uso + video corto (reutilizable de las grabaciones para redes).
4. **Conectar con Contenido**:
   - Devolver 1 ángulo de video breve para que `guionista-hooks` pueda grabarlo y usarlo tanto en Reels como en la publicación de Mercado Libre / Web.
5. **Pendientes para la dueña**:
   - Listar qué dato falta confirmar (costo, margen mínimo, stock reservado para online, modalidad de despacho).
